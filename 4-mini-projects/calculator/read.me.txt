# 🎯calculator (Python)

A simple  ** calculator ** built using Python.
The program asks your choice **ADDITION,SUBSTRACTION,MULTIPLICATION,DIVISION**, and the user select operator then provide two inputs .

---

## 🚀 Features

* 🔢 Asks choice ADDITION,SUBSTRACTION,MULTIPLICATION,DIVISION.
* 📈 Takes two inputs from the user.
* 🔁 Do the calculation user select with the provided inputs.
* ⚠️ Input validation (handles invalid inputs gracefully)
     shows ZeroDivisionError "error can not divide by zero".
* 🎉 Display result beautifully
* 🔄 Ask if user want to do further calculation.

---

## 🛠️ Tech Stack

* Python (Standard Library)

  * `random` module

---

## 📂 How to Run

1. Make sure Python is installed on your system
2. Clone this repository:

```bash
git clone https://github.com/mrrendex2006/python-beginner-to-advance.git
cd python-beginner-to-advance
```

3. Run the script:

```bash
python calculator.py
```
