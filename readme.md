# 🐍 Python: Beginner to Advance

Welcome to the ultimate Python learning roadmap! This repository is designed to take you from writing your very first `print("Hello World")` all the way to building advanced, production-ready applications.

---

## 🗺️ Learning Roadmap

### 🟥 Phase 1: Beginner (The Fundamentals)
*   [Variables & Operators](./1-beginner/01_variables.py) — Understanding data storage.
*   [Data Types](./1-beginner/02_data_types.py) — Strings, Integers, Floats, Booleans.
*   [Control Flow](./1-beginner/03_conditionals.py) — `if`, `elif`, `else` logic.
*   [Loops](./1-beginner/04_loops.py) — Iterating with `for` and `while`.
*   [Functions](./1-beginner/05_functions.py) — Writing reusable code blocks.

### 🟨 Phase 2: Intermediate (Expanding Your Skills)
*   [File I/O](./2-intermediate/01_file_handling.py) — Reading and writing files.
*   [Object-Oriented Programming](./2-intermediate/02_oop_basics.py) — Classes, Objects, Inheritance.
*   [Error Handling](./2-intermediate/03_exception_handling.py) — Using `try/except` gracefully.

### 🟩 Phase 3: Advanced (Mastery)
*   [Decorators](./3-advanced/01_decorators.py) — Modifying function behavior.
*   [Generators](./3-advanced/02_generators.py) — Memory-efficient data streams.
*   [Concurrency](./3-advanced/03_concurrency.py) — Multi-threading and AsyncIO.
